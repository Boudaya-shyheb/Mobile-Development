# CarShare

Flutter starter project for the CarShare user management module: welcome, sign in, sign up, password recovery, profile storage, and home/sign out.

## Firebase

The project includes `android/app/google-services.json`. Its Android package matches the app ID `com.example.carshare` in `android/app/build.gradle.kts`. The Google Services Gradle plugin is declared in `android/settings.gradle.kts` and applied in `android/app/build.gradle.kts`; it supplies the native Firebase options used by `Firebase.initializeApp()`.

In the [Firebase Console](https://console.firebase.google.com/), confirm that **Authentication → Sign-in method → Email/Password** is enabled and that a **Cloud Firestore** database exists. Publish the included `firestore.rules` from **Firestore Database → Rules** before testing profile creation. The app uses real Firebase services and does not fall back to demo accounts. New profiles are stored in `users/{uid}` with `fullName`, `phone`, `email`, `role`, and a server timestamp in `createdAt`.

The Android package is configured. iOS needs the registered app's `GoogleService-Info.plist`; web needs Firebase web options generated by the FlutterFire CLI.

## Run on an Android emulator

Start an Android emulator from Android Studio's Device Manager and run:

```sh
flutter pub get
flutter run
```

Create an account using the Sign Up form. Enable email/password auth and Firestore before testing registration, sign in, password recovery, and sign out.
